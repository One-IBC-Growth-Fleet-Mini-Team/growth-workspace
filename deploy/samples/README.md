# File mẫu để nạp (dữ liệu giả)

Mỗi file có đủ cột theo bảng ghép mặc định (`deploy/crm-columns.example.json` cho file CRM) và 3 dòng giả, không có dữ liệu khách thật. Tải từ trang web (link "File mẫu" cạnh từng ô nạp) hoặc mở thẳng thư mục này. Dùng để thử nạp, hoặc để đối chiếu tên cột khi xuất file thật.
